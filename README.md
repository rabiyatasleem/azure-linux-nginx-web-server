# Azure Linux Nginx Web Server

## Project Overview

Hands-on cloud deployment project using Microsoft Azure.

I created an Ubuntu Linux virtual machine on Azure, connected to it through SSH, installed and configured Nginx, and deployed a custom web page.

## Technologies

- Microsoft Azure
- Azure Virtual Machine
- Ubuntu Server 22.04 LTS
- Linux
- SSH
- Nginx
- HTML

## What I Implemented

- Created an Azure Linux Virtual Machine
- Configured Azure networking
- Connected to the VM using SSH
- Managed the Linux server through the terminal
- Installed Nginx
- Configured HTTP access
- Deployed a custom HTML webpage
- Verified the application through the public IP
- Documented the deployment

## Architecture

Internet
↓
Azure Network
↓
Azure Linux VM
↓
Nginx
↓
Custom HTML Website

## Result

A working web server was successfully deployed on Microsoft Azure.
